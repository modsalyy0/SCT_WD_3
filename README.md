# SCT_WD_3

## Quiz Game Application

An interactive multiple-choice quiz game developed using HTML, CSS, and JavaScript.

### Features

- Multiple Choice Questions
- Previous & Next Navigation
- Score Calculation
- Progress Bar
- Correct/Incorrect Answer Highlighting
- Restart Quiz
- Responsive Design
- Modern Glassmorphism UI

### Technologies Used

- HTML5
- CSS3
- JavaScript
